# خرج خانه — مدیریت درآمد و هزینه‌های خانواده (اندروید)

برنامه‌ی فارسی (راست‌چین، تقویم شمسی، فونت وزیرمتن) برای مدیریت خرج خانه، ساخته‌شده با Flutter.
خروجی APK با GitHub Actions ساخته می‌شود؛ نیازی به نصب Android Studio ندارید.

## امکانات

**ثبت و دسته‌ها**
- ثبت درآمد (حقوق یا هر درآمد دیگر) و هزینه، هر کدام با تاریخ شمسی
- دسته‌های هزینه (گوشت، برنج، پزشکی، مسافرت، قبوض، اجاره و …) و منابع درآمد؛ قابل افزودن/ویرایش/حذف با رنگ و آیکون دلخواه
- علامت‌گذاری هر هزینه به‌عنوان «ضروری» یا «غیرضروری»
- جستجو در همه‌ی ماه‌ها (توضیح، نام دسته یا مبلغ)

**بودجه**
- سقف ماهانه برای هر دسته، برای همه‌ی ماه‌ها یا فقط یک ماه مشخص
- نوار پیشرفت، باقی‌مانده‌ی هر دسته و مانده‌ی تخصیص‌نیافته از درآمد
- هشدار هنگام رسیدن به ۹۰٪ سقف و عبور از آن

**برنامه‌ریزی** (تب «برنامه»)
- اقساط: تعداد و مبلغ، پیشرفت، دکمه‌ی «پرداخت شد» که هزینه را ثبت و سررسید را به ماه بعد می‌برد
- یادآورها: قبوض و پرداخت‌های ماهانه با اعلان
- تراکنش‌های تکراری ماهانه (حقوق، اجاره، …) که خودکار ثبت می‌شوند
- اهداف پس‌انداز با نوار پیشرفت و پیشنهاد مبلغ ماهانه
- یادآوری روزانه برای ثبت هزینه‌ها (در تنظیمات)

**گزارش**
- گزارش ماهانه: خلاصه، درصد پس‌انداز، میانگین هزینه روزانه، نمودار دایره‌ای دسته‌ها، ضروری/غیرضروری، روند ۶ ماه، بودجه در برابر خرج واقعی
- گزارش سالانه: خلاصه‌ی سال، پرهزینه‌ترین و کم‌هزینه‌ترین ماه، ماه‌به‌ماه (با لمس هر ماه به گزارش همان ماه می‌روید)

**ظاهر و امنیت**
- نمایش کارتی یا شبکه‌ای (دکمه‌ی بالای تب‌های تراکنش‌ها، بودجه و برنامه)
- قفل برنامه با رمز ۴ رقمی (پس از ۳۰ ثانیه خروج از برنامه دوباره رمز می‌خواهد)
- پشتیبان‌گیری و بازیابی: فایل JSON از همه‌ی اطلاعات (رمز قفل داخلش نیست)

داده‌ها فقط روی گوشی (SQLite) ذخیره می‌شوند و برنامه به اینترنت نیاز ندارد.

## ساخت APK با گیت‌هاب

1. یک مخزن (Repository) جدید در GitHub بسازید.
2. همه‌ی فایل‌های این پوشه را (از جمله پوشه‌ی مخفی `.github`) در شاخه‌ی `main` آپلود کنید.
3. به تب **Actions** بروید؛ workflow با نام **Build Android APK** خودکار اجرا می‌شود
   (یا «Run workflow» را بزنید). حدود ۵ تا ۱۰ دقیقه طول می‌کشد.
4. بعد از پایان، داخل صفحه‌ی همان اجرا در بخش **Artifacts** فایل `khane-budget-apk` را دانلود کنید.
   داخل آن `khane-budget.apk` است؛ روی گوشی نصبش کنید (اجازه‌ی نصب از منبع ناشناس لازم است).

> اگر یک تگ مثل `v1.0.0` روی مخزن بزنید، APK به‌صورت **Release** هم منتشر می‌شود.
>
> اگر بیلد خطا داد، متن خطا را از لاگ مرحله‌ی «Build release APK» بردارید و برای اصلاح بفرستید.

## نکات

- پوشه‌ی `android/` در مخزن نیست؛ workflow هر بار آن را با `flutter create` می‌سازد و با `tool/patch_android.py`
  مجوزها و تنظیمات اعلان را اضافه می‌کند.
- APK با کلید debug امضا می‌شود (برای نصب شخصی کافی است؛ برای انتشار در مارکت‌ها باید کلید release بسازید).
- اعلان‌ها با زمان تقریبی (inexact) تنظیم شده‌اند و ممکن است چند دقیقه دیرتر برسند. در اندروید ۱۳ به بالا،
  موقع اولین اجرا اجازه‌ی اعلان را تأیید کنید. در برخی گوشی‌ها (شیائومی، سامسونگ و …) باید برنامه را از
  «بهینه‌سازی باتری» مستثنی کنید.
- ساعت یادآوری‌ها بر اساس وقت تهران است.
- پولِ جمع‌شده برای اهداف پس‌انداز از «مانده ماه» کم نمی‌شود.
- تراکنش تکراری با تاریخ شروع گذشته، ماه‌های سپری‌شده را هم ثبت می‌کند.
- قفل برنامه رمزنگاری اطلاعات نیست و فقط جلوی باز کردن معمولی را می‌گیرد؛ اثرانگشت ندارد.
- بازیابی پشتیبان، همه‌ی اطلاعات فعلی را با محتوای فایل جایگزین می‌کند.

## اجرا روی کامپیوتر (اختیاری)

```bash
flutter create --platforms=android --org ir.khanevar --project-name khane_budget .
python3 tool/patch_android.py
flutter pub get
flutter run
```

## ساختار کد

```
lib/
  main.dart                 نقطه‌ی شروع، تم، راست‌چین و دروازه‌ی قفل
  data/                     مدل‌ها و دیتابیس SQLite (نسخه ۲)
  state/app_state.dart      منطق برنامه (بودجه، اقساط، تکراری، اهداف، قفل، گزارش‌ها)
  services/                 اعلان‌ها و پشتیبان‌گیری
  utils/format.dart         اعداد فارسی، مبلغ، تاریخ شمسی
  ui/                       صفحات: خانه، تراکنش‌ها، بودجه، برنامه، گزارش، تنظیمات، قفل
```
